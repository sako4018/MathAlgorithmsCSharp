# MathAlgorithmsCSharp

Математически алгоритми на C# — задачи от 11 клас, ПГЕЕ Пловдив.

## Задачи

### 1. Квадрати на числа
Извежда `i² - 1` за всяко число от N до 1.

### 2. Фибоначи
Генерира първите N числа от редицата на Фибоначи: 0, 1, 1, 2, 3, 5, 8, 13...

### 3. НОД (Алгоритъм на Евклид)
Намира най-големия общ делител на две числа чрез последователно остатъчно деление.

### 4. Перфектно число
Намира всички перфектни числа до N. Перфектно число = сумата на делителите му (без самото число) = самото число. Пример: 6 → 1+2+3 = 6.

```bash
dotnet run
```
