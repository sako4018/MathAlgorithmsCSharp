## Задача 7: Перфектно число

Перфектно число = сумата на делителите му (без самото число) = самото число.
Пример: 6 → 1+2+3 = 6.

Програмата намира всички перфектни числа до 10000: `6, 28, 496, 8128`.

Методи:

- `IsPerfectNumber(int n)` — проверява дали числото е перфектно
- `FindPerfectNumbers(int limit)` — намира всички перфектни числа до limit
